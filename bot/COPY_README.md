# RADIK AI BOT — копия

В архив входят полный код бота, Telegram-мост, зависимости, изображения и шаблон настроек.

## Настройки

Скопируйте `session-settings-19-00.env.example` в `.env` и задайте секреты `POCKET_SSID`, `TELEGRAM_BOT_TOKEN` и `GEMINI_API_KEY` в защищённом хранилище. Не публикуйте заполненный `.env` и не отправляйте секреты в чаты.

Шаблон настроен на канал `-1004331252612`, 19:00–21:00 по Киеву, дата `2026-11-16`. Перед запуском в другой день измените `RADIK_SESSION_DATE`.

## Запуск на одном хосте

Установите Python-зависимости:

```sh
python -m pip install -r requirements.txt
```

Запустите Telegram-мост и бота в двух процессах:

```sh
node --env-file=.env telegram_bridge.mjs
python radik_bot.py
```

Если хост передаёт секреты как переменные окружения, не создавайте `.env`; запускайте оба процесса в этом окружении.

Запускайте только один планировщик на один Pocket Option аккаунт. Не включайте копию параллельно с уже работающим ботом: это может вызвать дубли сигналов и конфликт соединений.
